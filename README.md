# Proyek

Pemrograman Mobile

## Tujuan

Aplikasi ini dikembangkan sebagai proyek pembelajaran untuk memenuhi tugas dan praktikum mata kuliah Pemrograman Mobile. Aplikasi ini direncanakan untuk membantu pengguna dalam melakukan latihan olahraga secara lebih teratur melalui panduan latihan dan pencatatan aktivitas.

## Rencana Fitur

1. **Panduan Latihan**

   Menyediakan panduan latihan olahraga yang dapat membantu pengguna memahami dan melakukan gerakan latihan dengan benar.

2. **Pencatatan Progres**

   Memungkinkan pengguna mencatat aktivitas dan perkembangan latihan yang telah dilakukan.

3. **Pengingat Latihan**

   Menyediakan pengingat agar pengguna dapat melakukan latihan sesuai dengan jadwal yang telah ditentukan.

## Cara Menjalankan

Proyek ini dibuat menggunakan Flutter. Sebelum menjalankan aplikasi, pastikan Flutter dan perangkat atau emulator yang digunakan telah dikonfigurasi dengan baik.

### 1. Mengambil Dependency

Jalankan perintah berikut pada terminal di dalam folder proyek:

```bash
flutter pub get
```
